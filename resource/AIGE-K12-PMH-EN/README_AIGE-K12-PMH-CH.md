## 二、AIGE 实践背景

人工智能正在进入知识生产、信息传播、判断形成和社会行动等基础社会活动。学生需要逐步理解人工智能的基本概念、方法、应用、风险、伦理与社会影响，并形成适应智能社会的思维方式、判断能力和责任意识。

清华大学人工智能通识教育体系（Artificial Intelligence General Education，AIGE）是在这一背景下形成的系统性教育实践。该体系连接基础教育、高等教育、教师教育和终身学习，由清华大学计算机科学与技术系、清华大学出版社、清华大学附属中学、清华大学附属小学及相关合作单位共同建设。

AIGE 采用多方协同的课程建设机制：大学和人工智能学者提供学术基础并规划知识结构，教育专家完成课程设计，一线教师通过课堂实践持续检验和完善教学内容。相关资源已经形成教材、课程、教学课件、学生手册、教学设计、教师培训和课堂试点相互衔接的体系，并在300余所试点学校开展实践，形成了200余名认证讲师参与的教学网络。

## 三、资源目标

本套英文资料旨在：

1. 帮助学校建立具有连续结构的 K–12 人工智能通识教育课程；
2. 为教师备课、课堂讲授、讨论和学生活动提供直接支持；
3. 降低学校和公益教育组织启动人工智能通识教育课程的资源门槛；
4. 支持教师培训、课程试点和教学研究；
5. 为不同国家和地区开展课程翻译、本地化和适应性设计提供基础；
6. 帮助学生理解智能时代的基础知识，发展批判性判断、伦理意识、责任意识和认知自治能力。

## 五、从小学到高中的学段递进

三册教材及其配套资源遵循“故事与体验—知识网络—深入探索”的递进结构。

### 小学阶段：从故事与体验开始

小学阶段通过故事、图像、人物、历史事件、日常智能应用和课堂活动，引导学生接触人工智能。学习重点包括激发兴趣、建立初步认识、形成基本的安全意识、诚实意识和责任意识。

### 初中阶段：形成知识网络

初中阶段将学生已有的体验组织为相互关联的知识结构。学生开始系统理解人工智能的基础概念、典型任务、应用场景、技术方法和社会问题，并逐渐认识数据、模型、训练、输出和评价之间的关系。

### 高中阶段：开展深入探索

高中阶段进一步讨论人工智能原理、前沿技术、复杂系统、人机协同、伦理风险、社会影响和未来发展。学生需要分析更加复杂的案例，理解技术能力的边界，并对人工智能应用中的选择、风险和责任作出判断。

## 六、小学 PPT 的 L1 与 L2 双层设计

小学阶段的每一课提供两个层次的 PPT：

* **L1：基础课堂版。** 图片较多、文字较少，适合直接用于课堂讲授、讨论和学生活动。
* **L2：拓展学习版。** 包含较多文字和背景知识，适合教师自学、备课、课程调整、本地化和教师培训。

双层设计既保持了课堂材料对低年龄学生的友好性，也为教师提供了更充分的知识背景和课程拓展空间。教师可以根据学生年龄、课堂时间和本地课程要求，选择使用 L1、L2 或将两者结合使用。

## 七、资源的主要特点

### 1. 覆盖完整的 K–12 学段

资源贯通小学、初中和高中，形成连续发展的课程结构，有利于学校进行长期课程规划。

### 2. 与完整教材体系配套

PPT、教学设计和学生讲义与清华 AIGE 系列教材相互衔接，支持从教材内容到课堂实施的转化。

### 3. 面向真实课堂

资源包含课堂讲授、讨论问题、学生活动和实施建议，可直接支持教师备课和教学组织。

### 4. 兼顾学生学习与教师发展

课堂材料保持清晰、直观和适龄，拓展材料为教师提供进一步理解人工智能知识和教育设计的空间。

### 5. 支持国际使用与本地化

英文资料为国际学校、海外教师、教育组织和本地化团队提供基础资源。使用者应根据当地课程标准、文化背景、学生特点、法律政策和语言习惯进行审慎调整，并在规定的授权范围内使用。

## 八、建议使用方式

首次使用本资料时，建议按照以下步骤进行：

1. 阅读本 README 及 Zenodo Record 中的发布与使用说明；
2. 根据小学、初中或高中选择相应 PPT 压缩包；
3. 查看对应教材、教学设计和学生讲义；
4. 根据课时、学生年龄和已有知识选择教学内容；
5. 核查案例、工具、平台和第三方材料在当地的适用性；
6. 完成必要的语言、文化和课程标准适配；
7. 在正式教学前由教师完整试讲或预演；
8. 记录课堂反馈，并通过 GitHub Discussions 或 Issues 提交建议。
